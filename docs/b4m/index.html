About

BEACH for MARBEFES (the B4M tool) is an updated and streamlined derivative of the original BEACH tool (Benefit Evaluation through Assessment of Component Habitats) developed by Wolds Environmental Consulting Ltd and described by Burdon et al. (2024).

This version of the B4M tool is © IECS Ltd. (2026).

The development of the B4M tool was made possible through the MARBEFES project (MARine Biodiversity and Ecosystem Functioning leading to Ecosystem Services), funded jointly by the European Union under the Horizon Europe program (grant agreement no. 101060937) and by UK Research and Innovation, UKRI (grant agreement no. 101060937).

Purpose

The B4M tool provides a consistent and transparent process for undertaking a benefit value transfer exercise, calculating the annualised value of 14 classes of societal benefits across a defined local target area using reference data from a wider area (e.g. available data reported at the national, or EEZ, scale).

Development

The underlying HTML code for the B4M tool was generated by Steve Barnard (IECS) using Claude, an online AI model by Anthropic, through an iterative process of instruction, review and modification. Outputs from the B4M tool were corroborated against outputs from the original BEACH Excel tool, to ensure that all supporting algorithms had been applied as intended. The resultant HTML file has been checked for malware using McAfee ‘Total Protection’, but you are strongly advised to perform your own security checks before running this application.

Use of the B4M tool

  • Data inputs to the B4M tool (with 'Input_1' detailing the habitat profiles at the national and local scales, and 'Input_2' recording estimates of the economic value of societal benefits at the national scale), are made on the second tab, 'User inputs'.
  • As flagged on-screen, inputs can be made directly into individual cells, or an entire array may be copied from (for example) an Excel source and pasted into a column in the the relevant table.
  • Note that, when pasting data into the tables, missing data or data that are recognised as being non-numeric, are imported as a zero values.
  • Once these inputs have been completed, click the 'Calculate outputs' button.
  • Outputs are provided on three separate tabs, which give: estimated economic value distributions across each habitat type at the national scale ('Output_1'); estimated economic value distributions across each habitat type at the local scale ('Output_2'); and estimated intrinsic economic values for unit areas of each habitat type ('Output_3').
  • If required, output tables can be exported (for example, to a spreadsheet or document, simply by highlighting cells on-screen and using standard copy/paste commands (ctrl.c/ctrl.v).
  • Finally, use the 'Restart' button to clear all inputs and reset the output tables.

The B4M tool (© IECS Ltd., 2026) provides:

  • estimates of annualised economic values of 14 defined societal benefits for a defined local scale ‘target’ area (i.e. specific region, site, or network of sites), detailed across 42 EUNIS (level 3) habitat types and 14 societal benefits.

The B4M tool requires:

  • estimates, at the national (e.g., EEZ) scale, of the annualised values of 14 defined societal benefits, using the Turner et al. (2015) framework; and
  • habitat profiles, using the 2026 EUNIS framework (EEA, 2026), at both the national (e.g., EEZ) scale, and the defined local scale ‘target’ area.

The operational approach followed by the B4M tool takes:

  • national scale (e.g., EEZ) annualised valuations for a range of 14 societal benefits, such as those valuations produced in the UK marine natural capital accounts (ONS, 2025); plus
  • breakdowns of the abundance of each of 42 discrete EUNIS marine habitat types at both the national scale and the defined local scale; and
  • the relative (quantitative) importance of each habitat for each societal benefit (based on the assessments presented within the Matrix Approach presented by Potts et al., 2014); and applies
  • a ‘joint normalisation approach’ — simultaneously considering both the relative abundance of each habitat at the national scale, and the relative importance of each habitat for each societal benefit — to distribute the overall economic value of each societal benefit across each of the habitat types represented at the national scale;
  • subsequently — and assuming that these ‘distributed values’ represent a first approximation of the true distribution of societal value across habitats — the B4M tool derives estimates of the specific economic value of each unit area of habitat for each societal benefit (this is further based on the assumption that, inter alia, all habitats are in a similar condition, and that any spatial variation in condition is similarly distributed at both the national and local scales); before
  • recombining these (disaggregated) unit-area values across the defined local scale (site/network/region) — based on the abundance of each constituent EUNIS habitat type at the local scale — produces derived annualised economic values for societal benefits at the new (target) scale.
